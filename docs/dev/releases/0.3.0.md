# Release record – 0.3.0 (2026-11-04)

trading-core `v0.7.0` and trusted loading: the module declares the
trading-core range it was tested on (`>=0.3.0,<0.8`), so trading-core's
trusted loading (its FEAT-89, FEAT-90) can check it, and a signed tag. No
lane, strategy, setting or fill changes; the pilots' results are not
changed by it.
