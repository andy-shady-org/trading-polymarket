# Release record – 0.4.0 (2026-11-04)

Two research commands for crypto Up/Down markets (FEAT-146): `updown-history`
collects every settled market of an asset and window with every taker trade
to the second, the outcome, Chainlink's start and end prices and one-second
Binance spot; `updown-backtest` replays the pre-registered late-longshot
rule on them. No lane, strategy, setting or fill changes; no run's result
changes. The backtest's verdict, **NO-GO**, is in
[`../RESULTS.md`](../RESULTS.md) (2026-11-04).
