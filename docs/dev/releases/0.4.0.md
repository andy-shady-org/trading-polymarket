# Release record – 0.4.0 (2026-11-04)

Research commands for crypto Up/Down markets. FEAT-146: `updown-history`
collects every settled market of an asset and window with every taker trade
to the second, the outcome, Chainlink's start and end prices and one-second
Binance spot; `updown-backtest` replays the pre-registered late-longshot
rule on them (verdict **NO-GO**, [`../RESULTS.md`](../RESULTS.md)).
FEAT-147: `ticks` records the current markets' best bid and ask, every fill
and Binance spot to the millisecond, `ticks-report` reads our latency and
how long stale asks live off a recording, and `updown-backtest --rule stale`
holds the pre-registered stale-quote rule. No lane, strategy, setting or
fill changes; no run's result changes. Needs trading-core 0.5.0 or later.

## Install in the runtime

```bash
cd ~/projects/git/trading/runtimes/polymarket
bin/install-release.sh v0.7.0 v0.4.0     # venvs/polymarket-v0.4.0/, venvs/current
```

Then the research commands run from the release copy
([`../RUNBOOK.md` §9](../RUNBOOK.md#9-research-from-a-release-copy)): first
`ticks` in its own tmux window for at least three days (FEAT-147, part 1).
No counted run is in progress; the stopped 0.2.1 runs keep
`polymarket-v0.2.1`.
