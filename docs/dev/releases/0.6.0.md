# Release record – 0.6.0 (2026-11-07)

The full-set scanner (FEAT-102), record-only, for the run `arb-1`
([`../runs/arb-1.md`](../runs/arb-1.md)): `arb` prices every open neg-risk
event's Yes set and No set on full books with each market's fee and walks
them for depth; `arb --loop` records every gap's lifetime, size, profit and
horizon for a week; `arb-report` gives FEAT-102's pre-registered decision.
Fixes TP-13 (partial sets read as gaps). Also carries the `ticks` read-out
of 2026-11-07 in the docs ([`../RESULTS.md`](../RESULTS.md)). No lane,
strategy, setting or fill changes; no run's result changes. Needs
trading-core 0.6.0 or later (unchanged).

Cut on 2026-11-07 at the operator's request, so that `arb-1` runs from a
release copy.

## Install in the runtime

```bash
cd ~/projects/git/trading/runtimes/polymarket
bin/install-release.sh v0.7.0 v0.6.0     # venvs/polymarket-v0.6.0/, venvs/current
venvs/polymarket-v0.6.0/bin/trading-polymarket --version   # must print 0.6.0
```

`venvs/current` moves to `polymarket-v0.6.0`; `weather-1` and `fed-1` keep
`polymarket-v0.4.0` and `sports-1` keeps `polymarket-v0.5.0` (each run names
its venv). Then `arb-1` starts from the release copy with `bin/record.sh`
([`../RUNBOOK.md` §9](../RUNBOOK.md#9-research-from-a-release-copy)), which
writes its `RUN.txt`. Installed 2026-11-07; the release copy says 0.6.0
and `arb-1` started from it at 14:45:07 UTC.
